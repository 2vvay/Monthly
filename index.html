/** * Monthly Cycle - Apps Script (스프레드시트에 바인딩된 스크립트) * 데이터는 시트 A1 셀에 JSON 문자열로 저장됩니다. * * 날짜별 항목에 u(마지막 수정 시각, ms)가 있고, * 병합 시 날짜마다 u가 더 큰 쪽이 이깁니다. (삭제도 u가 찍힌 '빈 항목'으로 기록) */ function jsonOut_(obj) { return ContentService.createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); } function readLogs_() { var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0]; var raw = sheet.getRange('A1').getValue(); if (!raw) return {}; try { var parsed = JSON.parse(raw); return (parsed && typeof parsed === 'object') ? parsed : {}; } catch (e) { return {}; } } function mergeLogs_(a, b) { var out = {}; var k; for (k in a) out[k] = a[k]; for (k in b) { if (!out[k] || ((b[k] && b[k].u) || 0) > ((out[k] && out[k].u) || 0)) { out[k] = b[k]; } } return out; } function doGet(e) { return jsonOut_(readLogs_()); } function doPost(e) { var lock = LockService.getScriptLock(); try { lock.waitLock(15000); // 두 사람이 동시에 저장해도 순서대로 처리 var body = (e && e.postData && e.postData.contents) ? e.postData.contents : '{}'; var incoming = JSON.parse(body); if (!incoming || typeof incoming !== 'object') throw new Error('invalid payload'); var merged = mergeLogs_(readLogs_(), incoming); var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0]; sheet.getRange('A1').setValue(JSON.stringify(merged)); SpreadsheetApp.flush(); return jsonOut_({ ok: true, logs: merged }); } catch (err) { return jsonOut_({ ok: false, error: String(err) }); } finally { try { lock.releaseLock(); } catch (x) {} } }
